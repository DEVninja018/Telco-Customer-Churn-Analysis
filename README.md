# 📞Telco-Customer-Churn-Analysis-Project 
📌This project focuses on analyzing and predicting customer churn for a telecommunications company using Python and EDA. By analyzing historical customer demographics, account information, and service usage patterns, this project identifies key churn drivers and builds predictive models.

This project delivers a **purely descriptive and exploratory data analysis (EDA)** of telecom customer behavior to identify the root causes of churn. By evaluating demographic profiles, account characteristics, and service utilization metrics, this repository establishes evidence-based business insights and data-driven customer retention strategies **without relying on machine learning predictive models**.


## 📁 Dataset Information
This analysis utilizes the popular IBM Telco Customer Churn Dataset sourced from Kaggle. The dataset tracks `7,043` rows (customers) and contains `21` raw attributes:
* **Demographics:** Gender, senior citizen status, and family status (partners/dependents).
* **Account Metrics:** Customer tenure, type of contract, payment method, paperless billing preferences, monthly charges, and total charges.
* **Services Opted:** Phone lines, internet type, online security, device protection, tech support, and streaming media.
* **Target Metric:** `Churn` (Whether the customer left within the last month—Yes/No).

* ## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation:** `Pandas`, `NumPy`
* **Data Visualization:** `Matplotlib`, `Seaborn`
* **Environment:** Jupyter Notebook / VS Code

* ## 📈 Key Insights & Strategic Findings
* **Contract Risks:** Customers operating on month-to-month contracts present a drastically higher churn rate compared to those on one- or two-year commitments.
* **Tech Support Vulnerabilities:** Users lacking technical support or online security options consistently demonstrate elevated attrition rates.
* **Payment Pain Points:** Customers configured with Electronic Check payment methods show a higher propensity to leave than those utilizing automatic bank transfers or credit cards.
* **Tenure Thresholds:** New customers are highly volatile; the first 6–12 months denote a critical risk window, after which loyalty increases sharply.
